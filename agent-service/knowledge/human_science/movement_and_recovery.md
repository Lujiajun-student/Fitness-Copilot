# 运动人体科学：运动适应与个体限制

来源：https://www.who.int/publications/i/item/9789240015111
审核日期：2026-10-12

## 人群差异与适用范围

身体活动指南区分成人、老年人和慢性病等人群。个体能力和医疗限制会影响活动选择。通用知识不能替代个体评估，也不能用于诊断疾病。

## 膝盖旧伤与低冲击替代（项目应用规则）

用户报告膝盖旧伤、关节疼痛或避免跳跃时，力量和体能计划必须遵守限制。需要真正替换动作，不能仅添加免责声明，也不能自动开具康复处方。低冲击活动也需要用户耐受；出现疼痛应停止并寻求专业评估。未填写不能解释为无伤病。

## 恢复与营养协作（项目应用规则）

恢复同时考虑负荷、睡眠和饮食。力量 Agent 关注动作安排，体能 Agent 关注累积活动量，营养 Agent 依据最终训练日规划普通饮食。不能承诺固定日期的适应效果。
